# TeleVip

Privacy, ad blocking and quality-of-life features for Telegram and its forks, as a modern
Xposed module (libxposed API 102).

## Features

- **Privacy:** Ghost Mode (no *seen*, *typing* or *online*), hide your phone number, hide story
  views, show deleted messages, keep secret media from self-destructing, show user IDs.
- **Media & stories:** save protected stories, voice messages and secret media, always allow
  saving media, faster downloads, local Premium, Hijri and Persian dates.
- **Chats:** remove content-saving restrictions, save message edit history, hide pinned messages,
  disable stories, disable swipe-back, jump to any message, hide app update prompts.
- **Block ads:** sponsored posts, video and search ads, and the proxy sponsor channel.

TeleVip's settings live inside the client's own **Settings**.

## Supported clients

Telegram (Play Store, Web, Beta), Nekogram, Cherrygram, Nagram, NagramX, Forkgram,
Forkgram Classic, Mercurygram, Plus Messenger, Nicegram, iMe and more. The last five releases of
the open-source ones are checked automatically every week. The full list is in the
[project README](https://github.com/2B-4G10/Re-TeleVIP#-supported-clients).

## Requirements

- LSPosed 1.10+ or Vector 2.2+ (libxposed API 102)
- Android 8.1 or newer

## Install

1. Install the APK and enable **TeleVip** in LSPosed / Vector.
2. Tick your Telegram clients in its scope.
3. Force stop the client and open it again.

Source code, issues and the changelog: https://github.com/2B-4G10/Re-TeleVIP
